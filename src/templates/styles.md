# 10种流行CSS设计风格库

## 1. modern - 现代简约
```css
--primary: #2563eb
--bg: #ffffff
--text: #1e293b
```
特点：简洁大方，色彩纯净，留白充足

## 2. minimal - 极简主义  
```css
--primary: #000000
--bg: #ffffff
--text: #333333
```
特点：黑白灰调，极致精简，重点突出

## 3. bento - 卡片网格
```css
--primary: #8b5cf6
--bg: #f8fafc
--text: #0f172a
```
特点：卡片式布局，网格排列，层次分明

## 4. brutalist - 粗犷野性
```css
--primary: #dc2626
--bg: #fef2f2
--text: #18181b
```
特点：原始粗犷，线条硬朗，对比强烈

## 5. glass - 毛玻璃
```css
--primary: #0ea5e9
--bg: #0f172a
--text: #f1f5f9
```
特点：磨砂玻璃效果，半透明模糊，现代科技感

## 6. neumorphic - 柔光拟态
```css
--primary: #6366f1
--bg: #e0e7ff
--text: #1e1b4b
```
特点：柔和光影，凸凹立体，手感细腻

## 7. gradient - 渐变色彩
```css
--primary: #f97316
--bg: #fff7ed
--text: #7c2d12
```
特点：多彩渐变，流动感强，视觉冲击

## 8. dark - 暗黑模式
```css
--primary: #22d3d1
--bg: #09090b
--text: #e4e4e7
```
特点：深色背景，护眼舒适，高对比度

## 9. cyber - 赛博朋克
```css
--primary: #ff0080
--bg: #0a0a0f
--text: #00ff9f
```
特点：霓虹灯效，未来科技，赛博风格

## 10. nature - 自然清新
```css
--primary: #16a34a
--bg: #f0fdf4
--text: #14532d
```
特点：自然色调，生机盎然，舒适放松
